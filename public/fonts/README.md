# Self-hosted webfonts

Barlow Condensed (600, 700) for display and Inter (400, 500, 600) for text/UI,
latin subsets only, downloaded from the Fontsource distributions of the Google
Fonts releases. Only the weights the site actually uses are shipped, and
`@font-face` declarations live in src/styles/base.css with `font-display: swap`.
